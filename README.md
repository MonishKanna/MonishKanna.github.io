## 🚀 Setup & Customization

### Prerequisites
- Node.js (v20+)
- npm (v10+)

### Installation

```bash
# Clone the repository
git clone https://github.com/MonishKanna/MonishKanna.github.io.git
cd MonishKanna.github.io

# Install dependencies
npm install

# Start development server
npm start
```

### Customizing Your Portfolio

1. **Edit Personal Information**
   - Open `src/portfolio.js`
   - Update experience, education, skills, certifications
   - Update social media links

2. **Fetch GitHub Data**
   ```bash
   node git_data_fetcher.mjs
   ```
   This will fetch your pinned projects, pull requests, and issues.

3. **Build for Production**
   ```bash
   npm run build
   ```

4. **Deploy to GitHub Pages**
   ```bash
   git checkout gh-pages
   cp -r build/* .
   git add -A
   git commit -m "Update portfolio"
   git push origin gh-pages
   git checkout main
   ```

### Change Theme

Edit `src/theme.js` and select your preferred theme:
```javascript
export const chosenTheme = blueTheme; // Change this
```

## 📝 Environment Variables

Create a `.env` file in the root directory:

```
GITHUB_TOKEN=your_github_token
GITHUB_USERNAME=your_username
```

Get a GitHub token from: https://github.com/settings/tokens

## 🌐 Deployment

This portfolio is deployed on GitHub Pages at: https://monishkanna.github.io

To deploy your own:
1. Create a repository named `<your-username>.github.io`
2. Update homepage in `package.json`
3. Run `npm run build`
4. Deploy the build folder to gh-pages branch
